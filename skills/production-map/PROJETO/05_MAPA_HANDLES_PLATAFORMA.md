# MAPA DE HANDLES DA PLATAFORMA

## Regra absoluta

Use o handle exatamente como aparece na biblioteca, inclusive erros, caixa, hífens, underscores e sufixos.

Nunca derive um handle do ID canônico.

Se não houver evidência, escreva `NÃO CONFIRMADO`.

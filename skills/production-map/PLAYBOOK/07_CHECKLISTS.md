# 07 — CHECKLISTS

## Antes de iniciar o projeto

- [ ] Roteiro completo colado.
- [ ] Modo de execução definido.
- [ ] Ferramentas identificadas.
- [ ] Duração máxima por geração conhecida.
- [ ] Proporção definida ou marcada como aberta.
- [ ] Política de música e diálogo definida.

## Antes de criar um asset

- [ ] Ele reaparece ou tem continuidade difícil?
- [ ] Já existe asset que resolve?
- [ ] O estado e a versão estão claros?
- [ ] A referência controla um papel específico?
- [ ] Contagens, anatomia e escala são verificáveis?
- [ ] O output está definido?

## Antes de aprovar um still

- [ ] Identidade correta.
- [ ] Materiais corretos.
- [ ] Contagem correta.
- [ ] Geografia útil.
- [ ] Escala útil.
- [ ] Sem personagens indesejados.
- [ ] Sem texto, logo ou watermark.
- [ ] Arquivo e handle registrados.

## Antes de dirigir um bloco

- [ ] Função dramática em uma frase.
- [ ] Último frame real consultado.
- [ ] Estado final desejado.
- [ ] Duração de montagem.
- [ ] Duração de geração.
- [ ] Transição anterior e seguinte.
- [ ] Assets aprovados.
- [ ] Handles auditados.
- [ ] Propriedade da tarefa confirmada.

## Antes de enviar prompt de vídeo

- [ ] Prompt completo num bloco copiável.
- [ ] Handles exatos, inclusive caixa e typo.
- [ ] Papel de cada referência descrito.
- [ ] Duração explícita.
- [ ] Planos temporizados.
- [ ] Câmera fisicamente descrita.
- [ ] Blocking e acting observáveis.
- [ ] Estado inicial verdadeiro.
- [ ] Estado final útil para montagem.
- [ ] Som diegético.
- [ ] `No music and no score`.
- [ ] Proibições específicas.
- [ ] Nenhum asset inventado.

## Ao assistir uma geração

- [ ] O que funcionou?
- [ ] Qual é o erro principal?
- [ ] O erro é local ou estrutural?
- [ ] Precisa de revisão, insert ou divisão?
- [ ] O frame final deve virar asset?
- [ ] A regra vale para cenas futuras?
- [ ] Registro atualizado?

## Antes de abrir tarefa paralela

- [ ] Escopo explícito.
- [ ] Blocos sem sobreposição.
- [ ] Arquivos compartilhados definidos.
- [ ] Fonte de verdade única.
- [ ] Último frame de cada fronteira registrado.
- [ ] Regra de sincronização aceita.

## Antes da montagem final

- [ ] Todos os blocos têm status.
- [ ] Transições cobertas.
- [ ] Alternativas identificadas.
- [ ] Continuidade de personagem revisada.
- [ ] Continuidade de props revisada.
- [ ] Continuidade de luz e direção revisada.
- [ ] Diálogo validado.
- [ ] Música adicionada fora das gerações.
- [ ] Som diegético disponível.
- [ ] Títulos adicionados fora dos clips.

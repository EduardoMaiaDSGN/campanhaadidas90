// ESPECIFICAÇÃO INDUSTRIAL

A Anatomia de um Tanque de Guerra

Reedição cirúrgica das especificações originais de 1996. Cada costura dupla e milímetro de espuma foram desenhados para suportar impactos severos.

SPEC 01 // CABEDAL
Camurça Bovina 2.2mm
Couro pesado de alta gramatura testado para resistir a mais de 500 atritos contínuos de lixa de skate sem abrir furos na biqueira.
SPEC 02 // PROTEÇÃO DE CANELA
Língua Puffy 18mm
Espuma densa de poliuretano acolchoada que protege o peito do pé contra caneladas violentas da tábua de madeira nos flips.
SPEC 03 // AMARRAÇÃO HISTÓRICA
Fat Laces 20mm
Cadarços extra largos em trama de algodão naval reforçado, com espessura que impede o rompimento prematuro na lixa.
SPEC 04 // AMORTECIMENTO MECÂNICO
Solado Gum Cupsole
Borracha pura vulcanizada de alta durabilidade com padrão serrilhado para máxima aderência no grip tape e absorção de drops altos.
